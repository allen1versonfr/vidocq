Removed from this app

Password resets, account-recovery tests, bulk account enumeration, arbitrary profile-page scraping, messaging, follow requests, contact syncing, login attempts by Vidocq, active scans, live DNS queries, archive submissions and unreviewed tools. Supplied Steam/Instagram accounts can be resolved through the explicit opt-in connectors; Osintgram manages its own backend access.

Passive does not mean invisible

Index mode does not fetch original pages. Opt-in Steam and Osintgram use platform/provider APIs, which can log access. Providers receive your query and connection information and may change behavior. No app can promise zero notification or anonymity. Opening an original result in an external search engine can contact that site; that happens outside this app.

Local data

Findings are saved to a local SQLite database, without encryption. Case reports preserve their queries and evidence. Ad hoc text queries are not automatically saved to Notebook. Imported documents are stored locally; SauceNAO upload images and its API key are not intentionally persisted. Steam keys remain in memory; Osintgram controls its own credential storage. No analytics, remote scripts, external fonts, thumbnails, or automatic provider account connections are included.

Framework attribution

Inspired by OSINT Framework (osintframework.com). The original directory is not executable in this app. The source-review.json file lists the directory entries excluded or replaced by these reviewed adapters.

FREE WEB SEARCH AVAILABLE
Choose your web search connection.
Basic web research does not require a paid service. Use Mwmbl's anonymous API without an account, key or payment. It has a smaller index and can miss profiles. Vidocq retrieves search titles/snippets, not original result pages.
Free Mwmbl access currently allows 1,000 requests per month per public IP at 1 request/second. Shared networks share that allowance. Vidocq caches repeated queries, spaces requests and stops on rate/quota errors. No Mwmbl key or billing account is used. Brave remains an optional provider with its own plan and charges.
Brave keys stay in memory and go only to api.search.brave.com. Free Mwmbl requests never receive this key. Existing VIDOCQ_BRAVE_API_KEY settings remain supported.
