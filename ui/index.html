Removed from this app

Password resets, account-recovery and account-existence checks, live profile views, username enumeration against platforms, messaging, follow requests, contact syncing, login attempts, active scans, live DNS queries, archive submissions, breach-credential search tools, and all unreviewed tools.

Passive does not mean invisible

The app does not intentionally notify a subject and does not contact their website or account. Providers still receive your query and IP address, may log requests, and may change behavior. No app can promise zero notification or anonymity. Opening an original result in an external search engine can contact that site; that happens outside this app.

Local data

Findings are saved to a local SQLite database, without encryption. Text queries are not automatically saved to the notebook. Images and SauceNAO API keys are not persisted. No analytics, remote scripts, external fonts, thumbnails, or automatic provider account connections are included.

Framework attribution

Inspired by OSINT Framework (osintframework.com). The original directory is not executable in this app. The source-review.json file lists the directory entries excluded or replaced by these reviewed adapters.
