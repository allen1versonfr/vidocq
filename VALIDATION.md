# Validation for Vidocq 2.5.0

72 automated tests pass locally. Added coverage includes international/national phone normalization, invalid values/regions/extensions, offline-only phone research, multi-input validation and deduplication, persistent editable cases, immutable report snapshots, selected evidence, explicit search consent, provider failures, safe self-contained exports, interrupted runs, live-process handling, parallel-run rejection and authenticated case/report HTTP routes. BUILD_INFO.json records the gates. Real-world identity matching is not established by these tests; source outages, quota limits and false-positive name matches remain possible. The native interactive window is not manually exercised by these automated checks.
