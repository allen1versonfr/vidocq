# Profile discovery follow-ups

Platform searches pair the supplied handle and name tokens on each platform, starting with Instagram and TikTok, then VSCO and LinkedIn. A four-query cap can therefore cover both term types on the first two platforms instead of one term type across four platforms. Existing caps remain unchanged. The report query diagnostics list platform queries that were not attempted. Increase the selected platform allowance only when broader coverage is desired; overall search and provider limits still apply.

When clue following and indexed-link following are enabled, a retrieved recognized profile matching an original case identifier or name can supply its observed handle for one bounded index-search hypothesis. The handle must differ from supplied handles. It is never added to case identifiers or marked as a confirmed alias. The follow-up retains its parent citation and uses the existing follow-up, depth, search, deadline and request limits. Rejected profiles, generated link-only leads, opaque IDs and sources without a case match cannot start this path. Hypothesis results are assessed against the original case and do not recursively propagate their handles.

A matching name may belong to a namesake. Hypothesis results need independent review; searching a handle does not establish account ownership. No direct authenticated profile access is added.

Synthetic engine tests verify execution, deduplication, parent provenance, disabled/zero-budget behavior, rejected sources and absence of automatic ownership promotion. These tests do not establish a live benchmark improvement.
